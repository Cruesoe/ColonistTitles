# Colonist Titles

Shows each colonist's title under their name on the colonist bar and on the map, along with their royal title and ideoligion role. With [LFS] UI Rethemed - Work, the work template assigned there can be used as the colonist's title. The settings page chooses which lines show where, how high they sit and their colors, with a full color picker and a live preview. Works with Colony Groups.
